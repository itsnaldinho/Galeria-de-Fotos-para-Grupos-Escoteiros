# Galeria-de-Fotos-para-Grupos-Escoteiros
Galeria de fotos e vídeos para grupos escoteiros, desenvolvida com Google Apps Script, Google Drive e Google Sheets. Permite organizar álbuns por ano e evento, exibir mídias em uma interface pública responsiva, pesquisar e filtrar conteúdos, favoritar fotos, compartilhar links e administrar álbuns por um painel protegido por senha, com praticidade.
